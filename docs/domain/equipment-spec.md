# 외부 서비스 제약조건

> Agent가 의존하는 외부 서비스의 제한사항입니다. 이 제약을 넘으면 장애가 발생합니다.

## GitHub API

| 항목 | 제한값 | 장애 시나리오 |
|------|--------|-------------|
| Rate Limit (PAT) | 5,000 req/hour | 대량 PR 동시 분석 시 429 에러 → fetch 노드 실패 |
| Rate Limit (App) | 5,000 req/hour/설치 | PAT과 별도 한도 |
| Diff 크기 | 300 파일 또는 3MB | 초과 시 diff 불완전 → 분석 누락 가능 |
| 코멘트 길이 | 65,536자 | 초과 시 코멘트 게시 실패 → comment 노드 FAILED |
| Webhook 응답 | 10초 이내 | 초과 시 GitHub이 재전송 → 중복 분석 트리거 |

## LLM API (OpenAI / Anthropic)

| 항목 | 제한값 | 장애 시나리오 |
|------|--------|-------------|
| 컨텍스트 윈도우 | 128K tokens (gpt-4o-mini) | 거대 diff 전송 시 토큰 초과 에러 |
| 최대 출력 | 16,384 tokens | 긴 응답 잘림 |
| Rate Limit | 플랜별 상이 | 동시 분석 다수 시 429 에러 → 노드 SKIPPED |
| 응답 지연 | 보통 3~15초 | 30초 초과 시 타임아웃 → 노드 SKIPPED |

## Redis

| 항목 | 설정값 | 장애 시나리오 |
|------|--------|-------------|
| 중복방지 TTL | 600초 | Redis 다운 → 인메모리 폴백 (중복 방지 약화) |
| 결과 캐시 TTL | 86,400초 | Redis 다운 → 매번 DB 조회 (성능 저하) |

## ChromaDB

| 항목 | 설정값 | 장애 시나리오 |
|------|--------|-------------|
| 컬렉션 | domain_docs | 컬렉션 미존재 → 자동 생성 (빈 상태) |
| 청크 크기 | 1,000자 | 너무 크면 검색 정확도 저하 |
| 검색 결과 수 | 최대 3건 | 문서가 적으면 노이즈 포함 가능 |
| 연결 실패 시 | domain_explain 노드 SKIPPED | 분석은 계속, 도메인 설명만 빠짐 |

## SQLite

| 항목 | 설정값 | 장애 시나리오 |
|------|--------|-------------|
| DB 파일 | ./pr_inspector.db | 파일 권한 문제 → 이력 저장 실패 (분석 자체는 정상) |
| 히스토리 조회 | 최대 50건 | 대량 데이터 시 조회 느림 → PostgreSQL 전환 고려 |
